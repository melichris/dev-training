## F-07c: Replace the Record-Based Mock Dataset

### 1. Objective

Resolve the remaining F-07c code-quality finding by removing the
`Record<number, Recipe>` mock dataset and the `Object.values()` conversion used
to load it.

### 2. Observation

The mock recipes were stored in an object keyed by numeric IDs, then converted
to an array with `Object.values()` before being assigned to the reactive recipe
list. Since the application operates on recipes as a list, this object shape
and conversion added unnecessary indirection.

### 3. Implemented Correction

- Changed `src/data/mockRecipes.ts` to export `mockRecipes` as `Recipe[]`.
- Updated `src/composables/useRecipes.ts` to check the array and copy it
  directly into reactive state, removing `Object.values()`.
- Updated `APPROACH.md` to document the array-shaped mock dataset.
- Updated the technical decisions in `REPORT.md` to record why the array is
  used instead of the object-and-conversion pattern.
