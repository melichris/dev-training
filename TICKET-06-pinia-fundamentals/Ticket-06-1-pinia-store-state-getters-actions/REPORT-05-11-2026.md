### Make Pinia concepts observable in the running app

- `CounterReactivityDemo.vue` now compares a directly destructured count
  snapshot with `count` and `doubleCount` extracted through `storeToRefs()`.
  Changing the counter leaves the snapshot at its original value while both
  refs update.
- The main page exposes the parameterized action, the action that calls
  another action, and a reset button.
- `CounterDisplay.vue` independently reads the shared store, making
  cross-component updates visible without props or emits.
- The theme store is active on the page, showing its derived label and
  `toggleTheme` action.
- Store state and getter return types are explicit. `npm run typecheck` is
  wired to `nuxt typecheck` and uses `vue-tsc`.
- The application README now reflects the actual Nuxt 4 project layout and
  documents the type-check command.
